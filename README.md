# Boardgame Site Frontend

Мінімальний багатосторінковий read-only сайт з мінімальним CRUD лише для ігор. HTML + CSS + JavaScript + jQuery з CDN.

## Сторінки

- `index.html` — каталог ігор з фільтрами
- `game.html?id=...` — деталі гри
- `game-form.html?id=...` — створення/редагування гри (лише адмін)
- `genres.html` — список жанрів
- `genre.html?id=...` — жанр та його ігри
- `hubs.html` — список хабів
- `hub.html?id=...` — хаб та його ігри
- `login.html` — сторінка входу
- `register.html` — сторінка реєстрації
- `profile.html` — профіль користувача (лише для авторизованих)

## Технології

- HTML5
- CSS3 (простий адаптивний CSS)
- JavaScript (ES5/ES6 сумісний)
- jQuery (CDN)

## Функціонал авторизації

- **Реєстрація** — `register.html`: форма з валідацією, помилки по полях з `error.details`.
- **Логін** — `login.html`: отримання `access` і `refresh` токенів, збереження в `localStorage`.
- **Профіль** — `profile.html`: доступний лише авторизованим користувачам. Неавторизований перенаправляється на `login.html?next=profile.html`.
- **Logout** — видалення токенів з клієнта (окремого ендпоінта на бекенді немає).
- **Авто-оновлення access** — при простроченні `access`-токена фронтенд автоматично викликає `POST /api/v1/token/refresh` і повторює запит без повторного логіну.
- **Ролі** — звичайний користувач (`user`) може переглядати каталог. Адміністратор (`admin`) додатково може створювати, редагувати та видаляти ігри.

### Поведінка навігації
- Неавторизований користувач бачить кнопки **"Увійти"** і **"Реєстрація"**, не бачить **"Вийти"**.
- Авторизований користувач бачить своє **ім'я** та кнопку **"Вийти"**, не бачить **"Увійти"**.
- Авторизований користувач не може відкрити сторінку логіну/реєстрації — перенаправляється на сторінку з контентом.
- Неавторизований користувач, що відкриває захищену сторінку, перенаправляється на логін, а після входу — повертається на сторінку, з якої його перенаправило.

### Зберігання токенів
Токени зберігаються в `localStorage`:
- `bg_access` — access-токен (час життя ~5 хв)
- `bg_refresh` — refresh-токен (час життя ~1 день)
- `bg_user` — кеш даних користувача

Заголовок для захищених запитів:
```http
Authorization: Bearer <access>
```

## Адреси та порти

- **Frontend:** http://localhost:5500
- **Backend:** http://127.0.0.1:8000
- **API:** http://127.0.0.1:8000/api/v1

## Як запустити проєкт

### 1. Запустити бекенд
```bash
cd boardgame_site
python3 manage.py runserver 127.0.0.1:8000
```

CORS вже налаштований для `http://localhost:5500` та `http://127.0.0.1:5500`.

### 2. Запустити фронтенд
```bash
cd boardgame_site_frontend
python3 -m http.server 5500
```

### 3. Відкрити у браузері
Відкрити http://localhost:5500
